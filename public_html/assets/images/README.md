# Image Assets

## Placeholder Images Needed

This directory should contain the following image assets for the Astroyds website:

### Hero Image (`hero-placeholder`)
Provide in multiple sizes and formats for responsive loading:

| Filename | Width | Format | Usage |
|---|---|---|---|
| `hero-placeholder-640.jpg` | 640px | JPEG | Mobile |
| `hero-placeholder-1024.jpg` | 1024px | JPEG | Tablet |
| `hero-placeholder-1920.jpg` | 1920px | JPEG | Desktop |
| `hero-placeholder-640.webp` | 640px | WebP | Mobile (modern) |
| `hero-placeholder-1024.webp` | 1024px | WebP | Tablet (modern) |
| `hero-placeholder-1920.webp` | 1920px | WebP | Desktop (modern) |
| `hero-placeholder-640.avif` | 640px | AVIF | Mobile (next-gen) |
| `hero-placeholder-1024.avif` | 1024px | AVIF | Tablet (next-gen) |
| `hero-placeholder-1920.avif` | 1920px | AVIF | Desktop (next-gen) |

### Recommended Approach
1. Create a single high-resolution source image (2560px+ wide)
2. Use a build tool or image processing script to generate all sizes/formats
3. Suggested tools: `sharp`, `imagemagick`, or `squoosh-cli`

### Brand Colors
- Deep Navy: `#0a0e27`
- Electric Blue: `#3b82f6`
- Purple: `#8b5cf6`

### Style Guidelines
- Dark, cosmic/space-themed imagery
- Gradients using brand colors
- Abstract geometric or nebula-style backgrounds work well
